# 04 — No-Code Automation

Learn to connect everyday business tools using visual blocks and menus, not code.

## What is automation?

**Automation (الأتمتة)** means a tool performs a repeated task automatically after something happens.

A simple automation has:

- **Trigger (المُحفّز):** the event that starts the workflow.
- **Action (الإجراء):** what the tool does next.
- **Condition (شرط):** a rule that decides whether an action should happen.
- **Workflow (سير العمل):** the complete sequence of steps.

## Example: a new inquiry

Imagine a fictional business receives a new inquiry through a form.

1. Trigger: a new form response arrives.
2. Action: add the inquiry to a tracking sheet.
3. Action: send an internal notification.
4. Human review: a sales representative checks the details before contacting the prospect.

This is a design example, not a promise that every app can connect on every free plan.

## Practice — no coding

Draw this workflow on paper or in diagrams.net:

**New sample inquiry → add row to sample sheet → notify sales → human reviews → follow-up task**

Label the trigger, each action, and the human approval step.

Do not connect automation to a real CRM, customer list, or company account unless you have explicit authorization. Check free-plan limits before choosing a tool.

## Beginner reminder

Start by understanding the process. Automating a confusing process only makes confusion happen faster.
